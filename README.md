# 🏥 Hospital Management System (HMS)

An enterprise-grade full-stack Hospital Management Web Application designed to streamline patient management, appointment scheduling, and administrative operations.

Built using modern web technologies with scalable architecture and secure authentication.

---

## 📌 Overview

The Hospital Management System (HMS) is a comprehensive platform that helps hospitals manage:

- Patients
- Doctors
- Appointments
- Medical Records
- Billing & Reports
- Role-Based Access Control

This system ensures secure, efficient, and scalable healthcare management.

---

## 🚀 Key Features

### 👨‍⚕️ Admin
- Manage Doctors & Staff
- View System Dashboard
- Monitor Appointments
- Manage Departments
- Generate Reports

### 🩺 Doctor
- View Assigned Patients
- Update Medical Records
- Manage Appointments
- Prescribe Treatments

### 🧑‍💼 Patient
- Register & Login
- Book Appointments
- View Medical History
- Download Prescriptions

## 🛠️ Tech Stack

### ⚛️ Frontend
- React.js
- React Router
- Axios
- Responsive UI (CSS / Tailwind / Bootstrap)

### 🧠 Backend
- Node.js
- Express.js
- RESTful API Architecture
- JWT Authentication
- Role-Based Access Control (RBAC)
